# Projeto Folha de Pagamento - Java

Sistema desenvolvido em Java para simular o cálculo de folha de pagamento,
aplicando conceitos de Programação Orientada a Objetos (POO) e regras de negócio.

## Funcionalidades
- Cadastro de colaboradores
- Diferentes tipos de funcionários
- Cálculo de salário final
- Listagem de colaboradores

## Tecnologias utilizadas
- Java
- Programação Orientada a Objetos (POO)
- Lógica de Programação

## Objetivo
Projeto desenvolvido com foco em prática constante e aprendizado contínuo,
visando evolução como desenvolvedor.
